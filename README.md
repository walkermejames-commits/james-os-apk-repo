ChipOS Studio 0.3.1 adds phone-based caption controls and a separate caption-only Android presentation window when the glasses are exposed as a separate display. Connect the glasses in Android display settings, then open **Glasses remote**. Start, stop, size, move, hide and test captions from the phone. In-app live captions use bundled offline speech and anonymous, provisional speaker labels. **Glasses output is view-fixed.** If Android only mirrors the phone, the caption display remains inside the phone UI; the app will report this limitation. No tracked 6DoF anchors are in this APK. S26/XREAL hardware testing remains pending. Signed with the existing experimental Android test certificate. [Release notes and checksums](https://github.com/walkermejames-commits/james-os-apk-repo/releases/tag/chipos-studio-0.3.1).

**Do not install the archived ChipOS Mark II keyboard demo for glasses use.** It shows simulated placeholder captions such as “Caption frame received”; they are not speech recognition.
