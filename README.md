ChipOS Studio 0.3.0 provides private editable project areas and on-device speech processing. Choose **Captions** to start listening, or **Float** to enable captions over other apps after granting microphone and overlay permissions. Use the overlay's Stop button to end background listening. Speaker labels are provisional. This is a native 2D/view-fixed build; Unity spatial anchors and S26/XREAL hardware validation are still pending. Signed with the existing experimental Android test certificate. [Release notes and checksums](https://github.com/walkermejames-commits/james-os-apk-repo/releases/tag/chipos-studio-0.3.0).
